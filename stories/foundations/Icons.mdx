# Icons

Use named exports from lucide-react for application icons.

## Rules

- Import only the icons used by a story or component.
- Use currentColor through semantic text tokens; do not hard-code SVG colors.
- Give icon-only controls an accessible aria-label.
- Use an icon to support meaning, not as the only way to communicate a critical action.
