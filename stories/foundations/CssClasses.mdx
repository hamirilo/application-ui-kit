# CSS Classes（テンプレート用）

Django テンプレート + htmx のアプリでは、画面上のボタン・入力欄・カードの大半が
**React ではなく素の HTML + CSS クラス**になります。このページはその見本です。

- 定義の SSOT: `tokens/theme.css` の `@layer components`
- React 側の対応: 各 Component の Story（対応表は[このページの最後](#css-クラスと-react-の対応)）
- 寸法の根拠（高さ・余白の導出）: Foundations/Spacing

以下の見本は Storybook が**実アプリと同じ `theme.css` を読んで**描画しています。
コードブロックはそのまま `.html` にコピーできます。

<DoDont
  doText={<><Code>{'<button class="btn-primary">保存</button>'}</Code></>}
  dontText={<><Code>{'<button class="h-8 px-3.5 bg-blue-600 text-white rounded-lg">保存</button>'}</Code></>}
/>

ユーティリティを毎回並べると、同じボタンが画面ごとに少しずつ違う状態になります。
クラスを使えば 1 箇所の修正が全画面に反映されます。

### 注意事項

- `<a>` にボタンの見た目を付ける場合も同じクラスを使えます。ただし
  **遷移なら `<a>`、処理実行なら `<button>`** です（新しいタブで開ける／Enter・Space で発火する、という期待が違います）
- 送信ボタンには `type="submit"`、それ以外には `type="button"` を明示してください。
  省略すると `<form>` 内では submit 扱いになり、意図しない送信が起きます

## 入力欄

<ClassSample
  sample={`<input type="text" class="input-field" placeholder="件名を入力">`}
  note="高さ・左右余白はボタンと同じ（32px / 14px）。横に並べたときに段差が出ないよう揃えています。"
/>

Django フォームでは `widgets` で指定します。テンプレート側には書きません。

```python
class IssueForm(forms.ModelForm):
    class Meta:
        widgets = {
            "title": forms.TextInput(attrs={"class": "input-field"}),
            "body": forms.Textarea(attrs={"class": "input-field", "rows": 5}),
            "status": forms.Select(attrs={"class": "input-field"}),
        }
```

### エラー表示

エラーは**色だけでなく必ず文言で**示します。赤枠だけでは何が悪いか分かりません。
`aria-invalid="true"` を付けると、支援技術にも不正な入力であることが伝わります。

<ClassSample
  sample={`<div>
  <label for="id_email" class="block text-sm font-medium mb-1.5">
    メールアドレス<span class="text-danger ml-0.5">*</span>
  </label>
  <input type="text" id="id_email" class="input-field" value="foo@" aria-invalid="true">
  <p class="mt-1.5 text-sm text-danger">メールアドレスの形式が正しくありません</p>
</div>`}
  note="余白は固定です: ラベル下 mb-1.5 / エラー上 mt-1.5 / ヘルプ上 mt-1。混在させないでください（Foundations/Spacing の固定ルール）。"
/>

React 側では `ApplicationFormField` がこの構造と余白を内部で持ちます。

## バッジ

`badge` は**形だけ**を定義しています（`rounded-full` / `text-xs` / `px-2 py-0.5`）。
色は別途クラスで渡します。

<ClassSample
  sample={`<span class="badge bg-yellow-50 text-yellow-600">未対応</span>
<span class="badge bg-sky-50 text-sky-600">対応中</span>
<span class="badge bg-emerald-50 text-emerald-600">完了</span>
<span class="badge bg-orange-50 text-orange-600">差戻し</span>
<span class="badge bg-rose-50 text-rose-600">緊急</span>
<span class="badge bg-purple-50 text-purple-600">保留</span>
<span class="badge bg-muted text-muted-foreground">アーカイブ</span>`}
  note="意味と色の対応は React 側の ApplicationBadge の tone と同じです。アプリ間で揃えてください。"
/>

**色だけに意味を持たせないでください。**セマンティックカラーはコントラスト比が
十分でないことがあるため、文字（「完了」「未対応」等）で意味が読み取れるようにします。

色の分岐はテンプレートに書かず、サーバー側（モデルのプロパティ等）で返します。

```html
<span class="badge {{ obj.status_display_class }}">{{ obj.get_status_display }}</span>
```

## カード

内側の余白と角丸は固定値ではなく、**中の見出しの大きさから導出**しています
（`card-sm` は見出し `text-sm`、`card` は `text-base`、`card-lg` は `text-2xl` を想定）。
`p-4` のような固定値を上書きで足さないでください。

<ClassSample
  sample={`<div class="card">標準カード</div>`}
/>

<ClassSample
  sample={`<div class="card-sm">card-sm</div>
<div class="card-lg">card-lg</div>`}
  note="card-sm / card-lg は単体で使えます（card との併記は不要）。"
/>

### 見出し付き

<ClassSample
  sample={`<div class="card">
  <div class="flex items-start justify-between gap-3 mb-3">
    <h3 class="text-base font-semibold leading-tight">申請一覧</h3>
    <button class="btn-primary btn-sm">追加</button>
  </div>
  <p class="text-sm text-muted-foreground">本文がここに入ります。</p>
</div>`}
  note="React 側は Card / CardHeader / CardTitle / CardAction / CardContent が同じ構造を持ちます。"
/>

### ルール

- インラインで `bg-white rounded-lg border p-4` と書かない（`card` を使う）
- **カードをカードの中に入れない**。境界が判別できなくなります
- 影は `shadow-sm` のみ（`card` に含まれています）

**CSS クラスを使うためだけに React Island を新設しないでください。**
逆に、React Island の中で `class="btn-primary"` を直書きしないでください
（`ApplicationButton` が持つ状態管理・アクセシビリティ対応が失われます）。

Island として置く判断基準は Getting Started/Django Islands を参照してください。

## ダークモード

このページのクラスはすべてトークン（`--color-card` / `--color-foreground` /
`--color-border` 等）を参照しているため、`.dark` の付与で切り替わります。
ツールバーの **Theme** で確認できます。

**テンプレートに `bg-white` や `text-gray-700` を直書きしないでください。**
その箇所だけダークモードで破綻します。地色は `card` / `bg-background`、
文字色は既定（`text-foreground`）または `text-muted-foreground` を使います。
